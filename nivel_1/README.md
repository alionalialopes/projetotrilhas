# Projeto PDV

## O que o código faz:

O código realiza a aplicaçao de descontos em um sistema de PDV(ponto de vendas).

## Como ele faz: 

Ao digitar o valor da compra e a idade do cliente, se a idade for maior ou igual a 65 será aplicado um desconto de 20%. E para os clintes com compras de o valor maior que R$100, será concedido um desconto de 10%.

A solicitação para preencher o valor e a idade sempre irá aparecer em sequencia, até que seja digitado o valor da compra igual a zero.
Após realizar os calculo será apresentado com valor com desconto. E os dados da compra serão adicionados a uma lista e somados os dados de numero de compras, total bruto, total desconto e total final.
Ao final os valores dessas variaveis são impressos em um resumo.

## Como rodar:
python pdv.py
